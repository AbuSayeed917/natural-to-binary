How accurately can AI write binary?

This lab measures it instead of guessing. Claude gets plain-English requests and writes WebAssembly. Every result runs in a sealed test chamber and is graded automatically against answers it never sees.

Sealed box. WebAssembly can only touch its own memory: no files, no internet, nothing on your computer. The lab gives it no outside access at all.
Separate room. Each binary runs in its own background worker, away from this page.
Time limit. A binary stuck in an endless loop is shut down after 1 second and marked as failed.
Memory limit. Binaries asking for more than 1 MB of memory are refused before they start.
This lab needs permission to ask Claude, and can't here. Open it on claude.ai while signed in.

Experiment A: plain English → raw bytes

30 number jobs, from “add three numbers” to “fewest coins to make an amount”. Two methods: Claude writes the whole binary, or only the function body while rules write the packaging. Failures are sent back for repair.

Experiment B: everyday requests → apps

20 everyday app requests. Claude rewrites each into Structured English, our compiler makes the binary, then the lab presses every button, sends keys and runs the timer for 3 seconds, to check it works without crashing.
