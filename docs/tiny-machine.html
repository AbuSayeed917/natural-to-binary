Talk to a tiny machine in plain English

Each word you write has its own piece of binary. Grammar rules plug the pieces together into a program the machine runs directly, then you click the screen to use it.

Words it knows so far

Colours: black, white, red, green, blue, orange, purple, teal, grey, salmon, lime, sky, yellow, lilac, charcoal, pink.

Things: square, box, block, rectangle, bar, dot, line, and the screen or background.

Sizes: tiny, small, medium, big, large, huge.

Places: middle, centre, top, bottom, left, right, top left, top right, bottom left, bottom right.

Clicks: “When I click the square, it turns green.” “When I click anywhere the screen changes colour.” “Clicking it again turns it back.” “A dot that turns red when I click it.”

Joining: “and”, “with”, and full stops between sentences. Words it doesn't know are listed in red so you can see where its English runs out.
