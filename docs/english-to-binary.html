Sentences it understands

Given n. or Given a and b. names the inputs. Always start with this.

Let x be …, Set x to … or x becomes … stores a value.

Add 1 to x, Increase x by 2, Decrease x by 1, Subtract 3 from x, Multiply x by y, Divide x by 2.

While … : (or Repeat while, As long as) starts a loop. Close it with End.

If … : and Otherwise:, closed with End. One-liners work too: If n is 0, return 1.

Return … gives the answer.

Maths: plus, minus, times, divided by, mod, squared, brackets, and numbers as digits or words up to twelve.

Comparisons: is, is not, is greater than, is less than, is at least, is at most, is divisible by, joined with and / or.

Lines starting with # are notes and are ignored. Whole numbers only (32-bit).

The honest catch: this understands a fixed set of English patterns, so it's really a programming language that reads like English. Understanding truly free-form English needs an AI model, which is where the API-key version of this project comes in.
