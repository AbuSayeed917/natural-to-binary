Structured English v0.2: six small apps, no code

Each app below is written only in English sentences. A rule compiler turns them straight into a WebAssembly binary for a 160 × 240 “tiny phone”, which draws every pixel, letter and number itself. Pick an app, use it, then change the sentences and watch it rebuild.
